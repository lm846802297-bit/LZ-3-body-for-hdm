# LZ 数据、事件率与统计重铸

## 1. 实验事实与研究目标

LZ Collaboration 的扩展核反冲分析报告：

- 曝光量：\(2.84\ {\rm tonne\!-\!year}\)；
- 数据时间：220 live days；
- 扩展核反冲窗口：约到 \(270\ {\rm keV}\)；
- 一个与核反冲相符的候选事件：
  \[
  E_R=248\pm23_{\rm stat}\pm23_{\rm sys}\ {\rm keV};
  \]
- 背景假设下的全局显著性：\(2.6\sigma\)；
- 被测试模型中的最大局部显著性：\(3.4\sigma\)。

来源：LZ Collaboration, arXiv:2609.02823，数据发布 DOI 10.17182/hepdata.182472.v1。

必须将其表述为高能核反冲 candidate/event of interest，而不是暗物质发现。理论任务是检验一个明确模型是否能解释该候选事件，同时满足相邻能区的无事件/低计数信息。

## 2. 本模型相对于通常非弹性散射的区别

常见 endothermic inelastic DM 模型是

\[
\chi_1+A\to\chi_2+A,
\]

其中暗物质吸收能量并跃迁到较重的末态。本文的三体机制则是

\[
\chi_1+A\to\chi_1+A+s.
\]

末态暗物质回到 \(\chi_1\)，额外的能量动量由辐射标量 \(s\) 承担。它可能改变核反冲谱，但不能先验地认为一定会增强 \(248\ {\rm keV}\) 附近或压低低能谱；这些都必须由完整的速度积分和探测器响应计算决定。

已有 LZ 解释包括模型无关的质量/质量劈裂后验研究，以及带暗光子的 endothermic 模型。本文的新增物理点应明确定位为：通过虚 \(\chi_2\) 中间态辐射轻标量产生三体末态，而不是仅重复一个两体非弹性散射拟合。

## 3. 从理论截面到事件数

首先由模型文档中的 halo 积分得到真实核反冲率 \(dR/dE_R\)。若 \(\mathcal E\) 是有效曝光量，\(\epsilon(E_R)\) 是真实反冲能量上的总接受效率，则接受事件数为

\[
N_s(\theta)=
\mathcal E\int_{E_{\min}}^{E_{\max}}
dE_R\,\epsilon(E_R)\frac{dR}{dE_R}(\theta).
\tag{1}
\]

这里 \(\theta\) 表示模型参数、halo 参数和必要的 nuisance 参数。若有能量分辨率，重建能量分布应写成

\[
\frac{dN_s}{dE_{\rm rec}}
=
\mathcal E\int dE_R\,
\epsilon(E_R)\,
G(E_{\rm rec}\mid E_R)\,
\frac{dR}{dE_R}.
\tag{2}
\]

\(E_R\) 是真实核反冲能量，\(E_{\rm rec}\) 是实验重建能量，两者不可混为一谈。若使用完整的 S1/S2 响应，则应直接构造 \(P(S1_c,\log_{10}S2_c\mid E_R)\)，而不是仅使用一个高斯能量分辨率。

LZ 的扩展分析窗口约为 \(270\ {\rm keV}\)，因此当前草稿把理论曲线画到 \(800\ {\rm keV}\) 可以作为研究谱形/侧带的诊断，但不能把 \(0\)–\(800\ {\rm keV}\) 全部当成 LZ 同一效率和同一信号区。每个能区的官方 ROI、接受率和背景定义必须从 LZ 原始分析与数据发布中核实。

## 4. 最低限度的能量谱似然

如果公开数据只足以支持能量维度的重铸，可以先建立明确标注为 approximate energy-only recast 的模型。对观测事件 \(E_i\)，扩展似然的基本结构可写为

\[
\mathcal L(\theta,\mu_b)=
e^{-(\mu_s(\theta)+\mu_b)}
\prod_{i=1}^{N_{\rm obs}}
\left[
\mu_s(\theta) f_s(E_i\mid\theta)
+\mu_b f_b(E_i)
\right]
\mathcal L_{\rm aux}(\nu),
\tag{3}
\]

其中 \(f_s\) 和 \(f_b\) 分别是归一化信号和背景能谱，\(\nu\) 表示背景/探测器 nuisance 参数，\(\mu_b\) 是背景期望计数。若使用多个能区，应将 signal region 和 sidebands 一并纳入，而不是只拟合 248 keV 单点。

单事件的中心能量和总误差可以用于初步诊断；但把统计误差和系统误差简单合并成一个高斯宽度，并不等价于 LZ 官方的 profile likelihood。若采用这种近似，必须明确标为简化模型，并与官方分析的背景和效率处理作对照。

## 5. 推荐的逐层重铸流程

### Level A：理论谱复现

1. 固定矢量媒介质量 \(m_V\)、暗物质质量、质量劈裂、标量质量及耦合。
2. 完成 \(v\) 积分，得到 \(dR/dE_R\)。
3. 先验证总事件率和谱形的数值收敛。
4. 将图中 benchmark 的参数全部列入表格，避免只有耦合乘积而缺少其组成参数。

### Level B：LZ 接受率与重建能量

1. 从 LZ 补充材料/HEPData 获取高能核反冲接受率及其不确定度。
2. 对接受率曲线进行可复现的数字化或读取官方表格，记录版本和插值误差。
3. 将真实反冲谱卷积到重建能量。
4. 核实候选事件的能量定义、分辨率、系统误差和 ROI。

### Level C：背景、侧带与统计检验

1. 使用 LZ 的背景模型或公开数据中能够支持的背景近似。
2. 同时检查候选事件附近、低能区和高能侧带。
3. 计算 best fit、profile likelihood、置信区间及参数相关性。
4. 与背景-only、普通弹性散射、两体 endothermic inelastic DM 作对照。
5. 明确区分 local significance、global significance 和模型参数拟合的置信区间。

## 6. 与现有 LZ 解释的对照

至少应对照以下两类文献：

- Palmisano, Tammaro and Tesi, arXiv:2609.15985：对两体 \(\chi+A\to\chi'+A\) 保留任意质量劈裂的精确运动学，研究 endothermic/exothermic 参数后验和低能伴随事件约束。
- Zhu et al., arXiv:2609.09015：显式暗光子模型，联合讨论 LZ 高能事件与遗迹丰度。

本文要展示的区别应是三体辐射机制本身带来的可观测变化，例如谱峰/端点、低能侧带比例、参数依赖以及不可见标量的能量分配。若三体谱在所有可观测量上都退化为已有两体模型，就需要重新评估新增模型的必要性。

## 7. 必须回答的实验问题

- 该 benchmark 在 LZ ROI 内预测多少个接受事件？
- 候选事件附近的重建谱是否与 248 keV 相容？
- 低能区是否被过量填充？
- 271 keV 以上的高能侧带是否过量？
- 预测是否对银河系速度分布的高速度尾部过度敏感？
- \(s\) 是否在探测器内外衰变为不可见 \(N_sN_s\)？是否存在可见衰变分支？
- loop-induced \(2\to2\) 过程是否产生无法隐藏的额外核反冲？

只有这些问题得到定量回答，才能判断模型是否真正解释了 LZ 候选事件。
