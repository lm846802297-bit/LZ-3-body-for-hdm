# Figure assets

The seven PDF figures are part of the original \`3body_for_HDM.zip\` source package. Their original byte sizes and SHA-256 hashes are listed in [../ASSET_MANIFEST.md](../ASSET_MANIFEST.md).

They have not yet been committed as individual binary files in this branch. Restore the original \`figures/\` directory from the supplied ZIP before running \`../build.sh\`. The figure names and relative paths must remain unchanged because they are referenced directly by \`main.tex\`.

No plots have been redrawn or numerically altered as part of this source import.
