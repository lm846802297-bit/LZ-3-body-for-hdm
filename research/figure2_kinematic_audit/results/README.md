# Kinematic audit results

This directory contains the archived outputs of the independent Figure 2 phase-space check.

| File | Purpose |
|---|---|
| `RESULTS.md` | Equations, benchmark assumptions, interpretation, and validation boundary |
| `phase_space_threshold.csv` | 25 rows: five incident speeds times five tested scalar masses |
| `run_manifest.json` | Parameters, execution environment, code/output hashes, and reproduction check |
| `SHA256SUMS.txt` | SHA-256 integrity record for the numerical CSV |

The CSV is a kinematic support table only. It is not a differential cross section, halo-folded rate, detector prediction, or likelihood result. The MeV-labelled benchmarks are retained as explicit zero-phase-space checks; no manuscript figure or original label is changed by this audit.
