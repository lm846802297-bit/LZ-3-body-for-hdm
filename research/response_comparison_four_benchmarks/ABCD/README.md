## 核子与原子核分别提供什么

| 名称 | 数学对象 | 物理内容 |
|---|---|---|
| 核子形状因子 | \(F_1^{V,N}(t_N),F_2^{V,N}(t_N)\) | 单个质子或中子的矢量流矩阵元。其动量依赖反映单个核子的内部强相互作用结构，进入单体算符的系数。 |
| 原子核响应函数 | \(W_M(y_A),W_{\Phi''}(y_A),W_\Delta(y_A),\ldots\) | 整个原子核内核子密度、自旋、轨道运动及其干涉的多体矩阵元。\(W_M(y_A)\) 已经包含原子核有限尺寸。 |

在靶静止系中取 \(Q_A=|\mathbf q_A|\)，\(Q_A^2=2m_AE_R+E_R^2\)，\(y_A=(b_AQ_A/2)^2\)。静态单核子冲量近似采用 \(t_N\simeq-Q_A^2\)。整核不变动量转移为 \(t_A=-2m_AE_R\)。表中保存了这三个量。A 到 D 全部沿用同一个 \(y_A\)。

| 版本 | 核子形状因子 | 原子核响应与核流 |
|---|---|---|
| A　原始有限尺寸基准 | \(F_{1,2}^{V,N}(0)\) | 仅 \(W_M(y_A)\)，电荷算符与 B 同阶，核子形状因子固定在零动量值。 |
| **B　核子形状因子修正** | **\(F_{1,2}^{V,N}(t_N)\)** | **仅 \(W_M(y_A)\)。本研究的分母。** |
| C　电荷型完整修正 | 同 B | 靶静止系仅保留 \(J^0\)。包括 \(W_M,W_{\Phi''},W_{M\Phi''}\)，最后一项是带符号的干涉。 |
| D　当前阶完整单体核流 | 同 B | 使用八类 AFH 响应及其匹配系数，保留六个非零对角或干涉响应。除 C 的电荷响应外，还有纵向电流，以及横向 \(W_\Delta,W_{\Sigma'},W_{\Sigma'\Delta}\)。 |

## 灰色空心菱形点线的定义

**“当前论文领先阶”**指用各面板的参数重新求值当前论文的三体微分截面公式。该式仅取靶静止系中核流时间分量 \(J^0\) 的相干密度 \(M\) 通道。核子静态矢量电荷 \(F_1^{V,N}(0)=3\) 已计入 \(g_{VN}=3g_{Vq}\)，所以核子电荷系数为 \(c_M=1\)。Pauli 形状因子 \(F_2^{V,N}\) 在该领先阶电荷中没有独立项。原子核则保留有动量依赖的有限尺寸响应 \(W_M^{00}(y)\)，上标 \(00\) 表示两个核算符均取同位旋标量通道。\(J^0\) 的上标才表示电流的时间分量。[当前论文三体截面公式](../../../paper-source/main.tex)

记 \(K_{00}(E_R)=P(E_R)L_{00}(E_R)\)，含共同的耦合、传播子和暗电流时间分量的三体相空间积分。\(b_A\) 是核谐振子长度，\(m_A\) 是靶核质量。用 \(131^2W_M^{00}(y)/W_M^{00}(0)\) 表示等质子、中子耦合下归一到 \(R_M(0)=131^2\) 的 Xe-131 响应。截面图的菱形线为

\[
S_6(E_R)=K_{00}(E_R)\,131^2\frac{W_M^{00}(y_6)}{W_M^{00}(0)},
\qquad y_6=\frac{b_A^2m_A E_R}{2}.
\]

比值图的菱形线用同一面板、同一反冲能的 B 作分母。消去共同因子后，

\[
\frac{S_6}{S_B}=
\frac{W_M^{00}(y_6)}{(c_M^B)^2 W_M^{00}(y_A)},\qquad
y_A=\frac{b_A^2(2m_AE_R+E_R^2)}{4}.
\]

A 使用 \(y_A\) 和静态 \(F_{1,2}^{V,N}(0)\)，在 \(M\) 电荷系数中保留 \(Q_A^2/m_N^2\) 阶反冲项。B 在同一算符中使用 \(F_{1,2}^{V,N}(t_N)\)。例如，在 267 keV，四组参数下灰色 \(S_6/S_B=1.38641\)，紫色 \(S_A/S_B=1.36996\)。灰线相对 A 高 1.20%。这里的 \(y_6\) 对应逐点 CSV 的 y_paper，\(S_6\) 与 \(S_6/S_B\) 分别对应 paper_cm2_per_keV 与 paper_over_B。[逐点数据](output/abcd_cross_sections.csv)

## 截面构造

采用等质子／中子耦合。有限 \(t_N\) 的核子输入取仓库实现的 isoscalar_zexp 中心值，将 Borah 等的同位旋标量电磁形状因子与 Bishara 等的奇夸克输入合并，奇夸克 Pauli 形状因子固定在零动量值。本次曲线使用中心参数，\(F_1^{V,N}(0)=3\)，\(F_2^{V,N}(0)=-0.552\)。令 \(f_i=F_i^{V,N}/3\)，以配合已包含核子矢量电荷的耦合 \(g_{VN}=3g_{Vq}\)。\(R_X\) 表示从原生 AFH \(W_X^{00}\) 统一换算到等核子耦合约定的响应。所有通道使用同一换算，\(R_M(0)=131^2\)。[Borah 等的核子形状因子](https://arxiv.org/abs/2003.13640) · [Bishara 等的夸克到核子匹配](https://arxiv.org/abs/1707.06998) · [AFH 原子核响应](https://arxiv.org/abs/1308.6288)

\[
c_\Phi=\frac{Q_A^2(f_1+2f_2)}{4m_N^2},\qquad c_M=f_1-\frac{c_\Phi}{2},
\qquad R_{\rm ch}=c_M^2 R_M+2c_Mc_\Phi R_{M\Phi''}+c_\Phi^2 R_{\Phi''}.
\]

用 \(L_{\mu\nu}\) 表示三体相空间积分后的暗电流张量，\(P(E_R)\) 表示公共散射前因子。令 \(c_M^A=c_M(Q_A;f_1(0),f_2(0))\)，积分、传播子、宽度和外部耦合在每条曲线中相同。各截面为

\[
S_A=PL_{00}(c_M^A)^2R_M,\quad S_B=PL_{00}c_M^2R_M,\quad
S_C=PL_{00}R_{\rm ch},\quad S_D=P(L_C R_{\rm ch}+L_T R_T).
\]

其中 \(r=E_R/Q_A\)，\(L_C=L_{00}-2r\,\mathrm{Re}\,L_{0L}+r^2L_{LL}\)，\(L_T=L_{11}+L_{22}\)，并且

\[
R_T=\frac{Q_A^2}{m_N^2}\left[
\frac{f_1^2}{2}R_\Delta+\frac{(f_1+f_2)^2}{8}R_{\Sigma'}
-\frac{f_1(f_1+f_2)}{2}R_{\Sigma'\Delta}\right].
\]

D 在当前单体非相对论展开中通过核流连续性 \(J_L=rJ^0\) 纳入纵向核流。\(W_{\Sigma''}\) 与 \(W_{\widetilde{\Phi}'}\) 的匹配系数在此阶为零。束缚核的独立振幅与相位匹配，特别是横向干涉和相互作用电流，仍是理论限制。以下 ppm 量度的是该模型中的 \(S_D/S_C-1\)。

## 复现与校验

从仓库根目录运行下列命令。依赖为 Python、NumPy、SciPy、pandas、Matplotlib 和中文字体，合订 PDF 另用 ReportLab 与 pypdf。

~~~powershell
python -B research/response_comparison_four_benchmarks/ABCD/run_comparison.py
~~~

计算读取[已独立验证的积分张量与原生核响应](../results/REPORT.md)。A–D 的主网格直接使用原生 AFH 动量节点，指定反冲能和端点附近的附加点使用 PCHIP 插值。灰色论文线按其 \(y_{\rm paper}\) 在同一响应表中取值。全部 4,482 个反冲点中有 4,474 个开放点和 8 个零截面端点，比值在这 8 点留空。逐点检查包括 \(S_B/S_B=1\)、A/B 与 C/B 的解析式、C 和 D 的已归档积分结果，以及用 12 个原生 Mathematica 截面节点重新加权后的 B。所有输出和相关源文件的 SHA-256 保存在运行清单中。
