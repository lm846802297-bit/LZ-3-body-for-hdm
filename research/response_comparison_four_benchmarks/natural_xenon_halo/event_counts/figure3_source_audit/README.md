## 独立绝对归一化检验

散射为 Dirac 暗物质的矢量流和标量 Yukawa 辐射。两个辐射顺序先相干相加，极点单衰变道宽度按当前 $g_2$ 为 4.733651656 MeV。辐射前传播子取 $+i0$，辐射后取 $+im_2\Gamma_2$。弹性核电荷取 $J^0_A=2m_A\sqrt{\mathcal R_A}$，$\mathcal R_A(0)=A^2$。$c_M=1$ 的曲线保留有限尺寸 $W_M^{00}(y)$，$y=b_A^2m_AE_R/2$。B 的 $F_{1,2}^{V,N}(t_N)$ 是另一个层次的核子输入。

以 $\mathbf q$ 为核反冲，$\mathbf K=\mathbf p_\chi-\mathbf q$，$c_q=\cos\angle(\mathbf p_\chi,\mathbf q)$，$\omega=E_s$。在实验室系直接从不变相空间积分掉末态暗物质三动量和能量守恒的角变量。积分整体核反冲方位角后，余下的单位反冲能相空间为
\[
\frac{d\Phi_3}{dE_R\,dc_q\,d\omega\,d\phi}=
\frac{|\mathbf q|}{128\pi^4|\mathbf K|}.
\]
这里 $\Phi_3$ 包含 $(2\pi)^4\delta^4$，$\phi$ 为标量绕 $\mathbf K$ 的方位角。实验室通量为 $4m_Ap_\chi$。算入 $|J_A^0|^2$ 并把 $d\phi$ 改为方位角平均，得到
\[
\frac{d\sigma_A}{dE_R}=
\frac{(g_1g_2g_{VN})^2\mathcal R_A m_A |\mathbf q|}
     {64\pi^3 p_\chi(m_V^2+2m_AE_R)^2}
\int dc_q\,\frac{1}{|\mathbf K|}\int_{\omega_-}^{\omega_+}d\omega\,\langle L_{00}\rangle_\phi .
\]
其中 $\omega_\pm=(K^0 E_s^*\pm|\mathbf K|k_s^*)/W$。程序直接用四维 $\gamma$ 矩阵收缩两张图，$L_{00}=\tfrac12\mathrm{Tr}[(\not p'+m_1)\Gamma^0(\not p+m_1)\bar\Gamma^0]$。该路径独立于归档程序的 $dW^2\,dz\,d\phi_*$、相空间权重和二分量自旋计算。一般不变相空间和入射通量的定义见 [PDG Kinematics](https://pdg.lbl.gov/2024/reviews/rpp2024-rev-kinematics.pdf)。

天然氙率使用各核零动量归一化后的原生 AFH 电荷表与 AME2020 质量。这些是两种实现共享的物理输入。Xe-128、129、130、131、132、134、136 的自然原子丰度合计 99.8158%，按自然丰度相加。每千克总核数采用全部九种同位素的平均摩尔质量。独立程序对平移后的银河系截断 Maxwell 分布直接积分入射方向，速度分布积分为 1.0000000000000036。取 $\rho_\chi=0.3$ GeV/cm³、$(v_0,v_{\rm esc},v_{\rm lab})=(220,544,232)$ km/s。速度流量、截面从自然单位到 cm²/keV、曝光到 kg·day 均在该程序中独立实现。

另一路低能检验从静态两体矢量截面乘正文三体相空间比出发，保留中介子动量分母，得到
\[
\frac{d\sigma_A^{I(D)}}{dE_R}=
\frac{m_A(g_1g_2g_{VN})^2\mathcal R_A I(D)}
{2\pi^3v^2\Delta^2(m_V^2+2m_AE_R)^2}.
\]
这里 $v$ 以光速为单位，$I(D)=\int_0^D d\epsilon\sqrt{\epsilon(\epsilon+2m_s)}$。这条领先常振幅路径使用远离极点的实传播子。两个窗的结果均较完整静态电荷计算高约 4.29%。该近似的选择在这组输入下不足以产生 4.8–6.8 倍差异。

## 运动学不相容之处与下一份必要输入

利用论文式 (23)–(24) 解 $W^2_{\max}=(m_{\chi_1}+m_s)^2$。用临界速等于 776 km/s 逐一检查全部九种天然氙的质量，所有允许反冲区间的并集为 **100.8875–702.8930 keV**。750 keV 至少需要 **787.7482 km/s**，对应 Xe-136，与正文非相对论近似值 787.7503 km/s 一致。原图红线在该处约有 $1.3544\times 10^{-7}$ 例/keV。最后一个可见红点在 796.002 keV，若解释为物理谱，则至少需要 799.26 km/s。这是速度下界，可见顶点的位置本身不足以测定原作者选定的截止。按图积分，允许区间外仅约 $8.25\times10^{-5}$ 例。这个尾部检验可以识别输入或绘图差异，窗内的数倍落差仍需要另行解释。

新版 TeX 在 Xe-131 等最小速度的算例中写了 220/544/232 km/s。图 3 的图注没有指定作图运行的实际速度分布、局域密度和七个或九个同位素清单，相关补充段落仍留有占位文字。要归因，应取得生成图 3 的数值表或 Notebook 以及该次运行的参数。首先核对速度分布及截断和蓝线的积分归一化，再在 248 keV 对照单同位素核响应、给定入射速度的 $d\sigma_A/dE_R$、该同位素的 halo 积分以及最终自然丰度加权。这个顺序可以区分作图约定、核结构、通量和绝对归一化的差异。
