# Native Xe-131 M / Phi'' AFH response export

This directory is reserved for the native Wolfram outputs generated by
run_afh_phi_response_xe131.wls.

Expected files after a successful local run:

- afh_default_xe131_M_PhiPP_native.csv: 2,401 rows containing the raw AFH
  \(W_M^{00}\), \(W_{\Phi''}^{00}\), \(W_{M\Phi''}^{00}\), and
  the raw/physical response normalizations.
- afh_default_xe131_M_PhiPP_metadata.json: AFH source and density-matrix
  hashes, Wolfram version, exact q grid, oscillator length, and normalization.
- validation_summary.json: output of validate_afh_phi_response.py.

No numerical output is present until the native Wolfram execution is run.
The detailed calculation and acceptance boundary are documented in
../audit/AFH_PHI_RESPONSE_XE131_NATIVE_PLAN.md.
