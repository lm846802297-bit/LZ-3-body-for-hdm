# A. vector–vector 模型：g₂ = 1 的 Mathematica 计算

## 文件与运行

- `Figure2_vector_vector_g2_1.nb`：主笔记本，包含中文解释、参数、自检、两套曲线、比值图及导出。
- `figure2_engine.wl`：完整 Wolfram Language 数值程序（运动学、两图相干自旋迹、三体积分、核响应、晕积分、宽度）；可以用 Mathematica 打开查阅。
- `dmformfactor-V6.m`：AFH 官方核响应程序，主笔记本校验源文件 SHA-256。
- `test_engine.wls`：数值和极点宽度测试，使用 `wolframscript -file test_engine.wls` 可单独执行。
- `g2_output/`：本机运行的曲线、宽度表、若干能量点对照与图像。

把这些文件保留在同一目录。打开主笔记本，从头逐个输入单元按 Shift+Enter，或使用 Evaluation → Evaluate Notebook。笔记本会计算零宽度和有限极点宽度两套曲线；执行最后的导出单元会覆盖 `g2_output` 中同名文件。第一节集中定义物理量。修改 `g1val`、`g2val`、`gVNval`、粒子质量、质量组合、晕参数或氙靶参数时，从第一节开始运行。第二节设置能量网格、对照能量及积分阶数。第三节负责把输入传给数值程序并计算极点宽度。完整运行可能需要数分钟。

主笔记本以 ASCII 加 Mathematica 原生字符转义格式保存，避免把 UTF-8 中文误按本地代码页解释。它的计算单元已在本机 Mathematica 内核中验证；图形前端的中文显示仍需要在桌面环境观察。

## 使用的模型与宽度

模型为用户指定的 A. vector–vector：矢量媒介 V 与暗费米子非对角矢量流和核子矢量流相互作用；g₂ 是发射标量 s 的非对角 Yukawa 耦合。具体取实标量与 Dirac 费米子、纯标量顶点 `g2 s bar(chi2) chi1 + h.c.`。在 `mchi2 = mchi1 + deltaM`，且只开放 `chi2 -> chi1 + s` 的假设下，采用此通道的极点分宽作为总宽：

```
Gamma = |g2|^2 sqrt(deltaM^2 - ms^2)
        [(2 mchi1 + deltaM)^2 - ms^2]^(3/2)
        / [16 pi (mchi1 + deltaM)^3]
```

当 `deltaM <= ms` 时，此通道关闭、分宽取零。质量、宽度在程序内部以 GeV 表示；分解形式减少 TeV 质量和 keV 分裂相减时的精度损失。具有一般左右手 Yukawa 耦合的相应两体宽度可对照 [Phys. Rev. D 101, 035026 (2020), Appendix A](https://doi.org/10.1103/PhysRevD.101.035026)，此处令左右手标量耦合相同。

按照现有原稿中的传播子，只有发射顺序对应的 `W²` 传播子加入 `+ i mchi2 Gamma`；另一项无宽度。两图幅度相加后再做自旋迹。即使采用有限宽度，程序仍要求 `Wmax < mchi2`；进入上壳区域会终止，避免将其当作已完成的离壳计算。

固定极点宽度是给定的 Breit–Wigner 近似，不是动量依赖完整一圈自能。如果实际有其他开放衰变道、Majorana 场或不同的顶点结构，应重新求宽度和传播子。

## 保持不变的参数

- `mchi1 = 1000 GeV`，`mV = 10 GeV`（后者是演示值，非已确认原图输入）。
- 第一节分别输入 `g1val`、`g2val` 和 `gVNval`。默认示例 `{1, 1, 1e-4}` 对应原图给定的耦合乘积平方 `1e-8`。程序由三个输入计算截面前因子，并按原稿约定计算 `gVqval = gVNval/3`。零宽度和有限宽度使用同一组耦合。第三节显示原稿的微分截面公式以及它与数值程序的对应关系。
- 四个 `(ms keV, deltaM MeV)` 分别为 `(200,1)`、`(300,1)`、`(360,1)`、`(300,10)`。第三、四条使用 keV 是条件假设：原图图例相应位置写了 360 MeV 和 300 MeV，而模型文字为亚 MeV，原始绘图输入缺失。
- 七种 AFH 默认天然氙同位素的数丰度和 0.998158，未包含 Xe-124、Xe-126，也不进行重新归一化。
- 局域密度 0.3 GeV/cm³；截断晕 v0=220、vEarth=232、vEsc=544 km/s；质量采用 A × 0.93149410242 GeV。

输出是理论事件率 events/(tonne year keV)，未包括效率、分辨率、背景或自然氙全部同位素；核响应与论文完整截面的总体归一化仍需最终审计。当前图并非原论文曲线的定量复现。

## 数值检查及精度

- 减小宽度到零后，I6 与原零宽度计算一致。
- `ms=300 keV, deltaM=1 MeV, g2=1`，精确因子化公式给 `Gamma=151.8239115788 keV`。
- `mchi=1000 GeV, mA=122 GeV, ER=200 keV, v=776 km/s`，积分阶数 `{16,16,8}`：零宽度 Mathematica I6=878098.5567396 GeV²；g₂=1 固定极点宽度 I6=868246.7879206 GeV²。与独立 Python 实现同阶数结果一致。
- 单 Xe-131、q=0.22 GeV、ER=198.3186730135 keV、mV=10 GeV、`{4,4,4}, nv=4`，g₂=1 有限宽度速度积分事件率：Mathematica `6.946449280116603e-6`，独立 Python `6.94644928011918e-6` events/(tonne year keV)。这只检验一个点和相同物理约定。
- 默认 `{nW,nz,nphi}={6,6,4}`，速度阶数 `nv=6`；绘图间隔 10 keV，另加 101、267、542 keV。笔记本提供 ER=200 keV 的粗细阶数对照。用于定量发表时必须对各 benchmark、阈值、谷底提高积分阶数并加密能量网格。

输出中 `rate_zero`、`rate_pole`、`pole_over_zero` 的耦合乘积完全相同；当零宽度曲线数值为零时，比值记为 `NA`。图中的“pole”与“zero”只表示传播子方案不同。
