# Figure 2 事件率曲线：Mathematica 程序说明

## 1. 从哪里开始

打开 `Figure2_rate_calculation.nb`。在 Mathematica 中从第一节开始，逐个输入单元按 Shift+Enter；也可使用 Evaluation → Evaluate Notebook。第一次执行计算四条曲线可能需要数分钟，具体时间由电脑和积分阶数决定。

请保持以下文件同目录：

- `Figure2_rate_calculation.nb`：带中文说明的主笔记本。
- `figure2_engine.wl`：实际使用的完整 Mathematica/Wolfram Language 数值程序。可用 Mathematica 打开检查，内部函数包括相干振幅、运动学、三体积分、核响应和速度积分。
- `dmformfactor-V6.m`：AFH 官方原始程序。笔记本运行时会检查 SHA-256。
- `original_figure2.pdf`：原稿中的 Figure 2 图片，方便对照。请注意该图片在原稿中的图注误写成费曼图，实际内容是事件率曲线。
- `Xe131_AFH_fixed.nb` 和 `python_reference.csv`：此前 Xe-131 核响应验证笔记本的编码修复版和比较数据。
- `figure2_output/`：已用本机内核生成的四条 CSV 和探索性图；再次运行导出单元会覆盖同名输出。

两个 `.nb` 均以 ASCII 加 Mathematica 字符转义格式保存，避免将 UTF-8 中文直接交由前端按其他编码解释。此前的 UTF-8 版在内核读取时可用，但没有验证图形前端，不能由此认定当时的前端显示正确。新旧核响应笔记本的表达式在 Mathematica 内核中比较完全相同。字符转义方法并不依赖 Windows 本地代码页；实际前端显示仍请以你的 Mathematica 打开结果为准。

## 2. 物理计算步骤

过程为 chi1 + A -> chi1 + A + s。程序依次计算：

1. AFH 默认密度矩阵与默认 b_A，逐同位素计算核响应；每个响应以自身 q=0 的数值统一缩放到 A²。
2. 标量在交换前、后发射两项的相干振幅，Dirac 外线自旋平均的 gamma 矩阵迹，包含两图干涉项。
3. 对 W²、cos(theta*) 和 phi* 作 Gauss–Legendre 积分；phi* 权重中包含 1/(2pi) 平均。
4. 对截断 Maxwell 晕的实验室速度分布进行积分，并对 AFH 有默认响应的七种天然氙同位素按数目丰度加权。
5. 用 0.3 GeV/cm³ 默认暗物质密度与阿伏伽德罗常数等换算到 events/(tonne year keV)。

程序中的原始响应与三体核按原稿公式组合；独立的完整论文归一化审计尚未结束，不能将上述步骤当作原论文最终截面前因子已确定的证明。

## 3. 默认参数及需要注意的假设

| 输入 | 默认值 | 状态 |
|---|---:|---|
| m_chi1 | 1000 GeV | 原图标注 1 TeV |
| (g1 g2 gVN)^2 | 1e-8 | 原图标注 |
| m_V | 10 GeV | 演示假设；原始作图输入未找到，可在参数单元修改 |
| 内线宽度 | 零 | 离壳诊断；程序在 Wmax >= m_chi2 时中止，不描述壳上极点 |
| 暗物质 | Dirac 基准 | 粒子统计性质须另行确定 |
| rho_DM | 0.3 GeV/cm³ | 可修改假设 |
| v0, vEarth, vEsc | 220, 232, 544 km/s | 可修改的截断晕假设 |
| 核质量 | A × 0.93149410242 GeV | 与此前诊断一致的近似 |
| 元素 | Xe-128、129、130、131、132、134、136 | 丰度合计 0.998158；未加入 Xe-124 和 Xe-126，不重新归一化 |
| 效率、能量分辨率 | 未加入 | 结果为理论核反冲率，而非完整探测器预测 |

四条基准默认是 `{m_s [keV], Delta m [MeV]}` = `{200,1}, {300,1}, {360,1}, {300,10}`。原图第三、四条图例分别写 360 MeV 与 300 MeV；以上 360 和 300 keV 是依据模型亚 MeV 质量范围作出的可检验假设，不是已核实的原作者绘图参数。若按图例字面输入 360000 或 300000 keV，本速度范围将关闭三体相空间。

输出曲线只用于给定假设下的探索，与原图纵轴量级存在明显差异；不能把图形相似误认为原图数值复现。原图灰色区域没有可靠来源，因此本程序不绘制该区域。

## 4. 精度与独立检查

- 默认 `quad -> {6,6,4}` 和 `nv -> 6` 是粗网格，可先运行；能量间隔 10 keV，并另外加入 101、267、542 keV。谷底的位置和深度不能只依赖该稀疏网格。
- 对所有曲线、各能量、阈值和谷底逐步提高 `{nW,nz,nphi}`、速度积分阶数 `nv`，并减小能量步长，以评估收敛。笔记本内置一个示例点的粗细对照。
- Xe-131、mA=122 GeV、mchi=1000 GeV、ms=300 keV、delta m=1 MeV、ER=200 keV、v=776 km/s、阶数 {16,16,8}：Mathematica I6=878098.5567396305 GeV²，Python I6=878098.5567396 GeV²。
- 截断速度分布积分 1.0000000000000047。
- Xe-131 单同位素、q=0.22 GeV、ER=198.3186730135 keV、mV=10 GeV、{4,4,4}、nv=4：Mathematica 7.021675792474143e-6，独立 Python 7.021675792476751e-6 events/(tonne year keV)。该比较只覆盖一个点和同一套 Dirac/零宽度物理约定。
- 七同位素混合、ER=200 keV、ms=300 keV：默认阶数为 6.7840861088e-6，提高到 {10,10,6}、nv=10 后为 6.7818678098e-6，前者相对后者高约 0.0327%。这不保证全图其他位置已收敛。

## 5. 范围与导出

`figure2_output/benchmark_1.csv` 到 `benchmark_4.csv` 是单条曲线的能量与事件率。图为 `figure2_exploratory.png`。纵轴是单位曝光、单位能量的微分率；需要在能量区间积分并乘以实际曝光才得到对应的理论事件数。缺少原始作图参数、完整探测器效率、分辨率和背景时，不可将本结果直接当作 LZ 的完整实验预测或原论文的定量复现。
