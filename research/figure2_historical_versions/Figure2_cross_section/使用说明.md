# Mathematica 核反冲微分截面与事件率

## 打开和运行

打开 `Figure2_截面与事例率.nb`。请保持同目录的 `figure2_engine.wl` 和 `dmformfactor-V6.m`，从第一节开始逐个输入单元按 Shift+Enter，或使用 Evaluation → Evaluate Notebook。笔记本中已保存一组固定速度截面及图形输出，修改任何参数后需从头运行以刷新这些输出。

工作区原有的 `Figure2_g2_1/Figure2_vector_vector_g2_1.nb` 是用户保存的笔记本；本文件从该版本复制并保留其输入。复制时读到的值为 `g1val=1`、`g2val=1`、`gVNval=1`，因此耦合乘积平方为 1。若选择 `gVNval=1.*10^-4` 且 g1、g2 不变，则乘积平方为 10^-8，当前同一截面和事件率会缩小 10^8 倍。请按需要在 1.1 节修改。

## 在笔记本中检查公式和计算

1. 第一节设置质量、三个耦合、质量组合和氙同位素。在 1.4 节设定固定速度截面的检查点，默认 Xe-131、第二组质量、ER=200 keV、v=776 km/s、极点宽度。
2. 3.1 节以 Mathematica 原生公式格式显示核反冲微分截面。`微分截面公式预览.png` 是 Mathematica 前端对该公式的渲染预览。
3. 3.5 节再次显示相空间积分 I6 及无量纲 Källén 函数，并依次输出核质量和动量、W² 上下限、极点宽度、AFH 核响应、I6、截面前因子以及 dσ_A/dER。前因子乘 I6 的表达式在该节的输入单元中直接写出。
4. 3.5 节还使用较高积分阶数重算这一点，显示粗细结果及相对差。3.6 节计算固定同位素、固定速度下，四组质量参数对应的微分截面曲线。`固定速度微分截面.png` 是当前输入的预览。
5. 后续章节对速度分布积分并按氙同位素丰度加权，得到 Figure 2 所需的理论事件率曲线。

核反冲截面公式为

```
dσA/dER = mA (g1 g2 gVN)^2 RA(ER)
           / [256 π^3 pχ1^2 (mV^2 + 2 mA ER)^2]
           × I6

I6 = ∫ dW² sqrt[λ(W²,mχ1²,ms²)] ∫ dz <L00>φ*
```

``Fig2`I6`` 数值计算后面的 W² 和 z 积分及方位角平均；``Fig2`NuclearResponse`` 计算 AFH 核响应；``Fig2`DifferentialCrossSection`` 计算固定速度的微分截面，单位 GeV^-3。笔记本 3.5 节另外明确计算相同的前因子乘 I6，并与该接口比较。``Fig2`Rate`` 使用相同的固定速度截面实现，再进行速度积分与同位素加权。

自然单位下截面以 GeV^-3 表示，乘 `0.3893793721 × 10^-27 × 10^-6` 得 cm²/keV。I6 的单位为 GeV²，公式中剩余前因子为 GeV^-5。

## 实现与检验

- `figure2_engine.wl` 中 I6 保留两张费米线图及其干涉项。核响应与固定速度微分截面是可单独调用的公开函数。
- 固定速度截面和晕积分事件率共用截面实现，避免展示的公式与最终曲线使用不同前因子。
- `test_cross_section.wls` 比较 Xe-131 的固定速度截面与独立 Python 参考值，覆盖极点宽度、零宽度与相空间关闭。可运行 `wolframscript -file test_cross_section.wls`。
- `test_rate_regression.wls` 将重构后的晕积分事件率与之前四个代表点比较。`test_engine.wls` 检查宽度和 I6。
- 核心计算保留 Dirac 基准、单一 χ2→χ1s 衰变道、固定极点宽度、相干核响应等原约定；天然氙仅使用 AFH 提供的七种同位素。事件率尚未计入探测器效率和能量分辨率。原稿截面总归一化和完整离壳自能仍需独立物理审计。
