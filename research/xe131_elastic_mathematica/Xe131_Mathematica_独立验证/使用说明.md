# Xe-131 AFH v6 Mathematica 独立验证

## 使用方法
1. 打开 `Xe131_AFH_独立验证.nb`。请保留本文件夹中的 `.nb`、`dmformfactor-V6.m` 与 `python_reference.csv` 在同一目录。
2. 在 Mathematica 中选择 Evaluation → Evaluate Notebook，或从顶部开始逐个选中输入单元，按 Shift+Enter。
3. 依次检查源文件哈希、零动量归一化、三个谷值及 2401 点比较表。比较结果三个项目的“未通过点数”应均为 0。
4. 运行最后的可选导出单元会在本文件夹下写入 `mma_output`，同名结果会被覆盖。目录内已包括本次内核验证产生的结果，可与重新运行的结果对照。

## 输入来源
- `dmformfactor-V6.m`：AFH 官方 DMFormFactor v6.0（https://www.ocf.berkeley.edu/~nanand/software/dmformfactor/），SHA-256：dc0742f1c50b0a478adab62f2ddef6c82978ee034c1f177e0ed917deab5dd372。
- `python_reference.csv`：研究仓库归档的 Python 结果，修复两处缺失换行和一个空行后的副本，包含 2401 个等间隔动量点。SHA-256：950cea3d0f7b4e542816c26fa89cd9c1c11613ce469749e81f164293e53315da。
- 笔记本直接运行 AFH 官方程序计算核响应；CSV 仅用于已有 Python 结果的比较。三体积分和截面不包含在本笔记本内。
