# AFH 七种氙同位素的物理核响应等价性与差异

## 1. 研究问题

本审计回答两个相互关联的问题：

1. AFH v6.0 的等标量 (M) 响应如何映射到论文中定义的物理单核子耦合 (g_p=g_n=g_N)？
2. 在相同核反冲能量下，不同 Xe 同位素的有限动量响应能否视为相同？

结论是：零动量下各同位素遵循相干电荷增强 (A^2)，但有限动量响应并不相同。特别是衍射极小值附近，同位素核结构差异会被显著放大。

本文件只讨论矢量电荷对应的核 (M) 响应，不把核自旋非零误认为必须存在暗物质自旋耦合。

## 2. 从单核子耦合到点状核

对等质子、中子耦合
[
g_p=g_n=g_N,
]
零动量转移时，核内各核子的电荷振幅相干相加：
[
mathcal M_A(0)propto
Zg_p+(A-Z)g_n=Ag_N.
]
因此，以 (g_N^2) 为粒子物理前因子的核响应必须满足
[
oxed{mathcal R_A^{m phys}(0)=A^2.}
]

有限动量下定义
[
F_A^2(q_A)=rac{mathcal R_A^{m phys}(q_A)}{A^2},
qquad F_A^2(0)=1.
]
这里的 (F_A^2) 是核电荷响应相对于点状核的平方振幅比。它不是暗物质速度分布，也不是三体末态标量的相空间因子。

## 3. AFH v6.0 的 factor-of-four 约定

AFH v6.0 分发的 Mathematica 实现对 isoscalar 系数采用
[
c^0=(c^p+c^n)/2.
]
在该程序的响应构造中，原始 package response
[
R_{m AFH}(q)=rac{4pi}{2J_A+1}W_{M,m AFH}^{00}(q)
]
在零动量满足
[
R_{m AFH}(0)simeq A^2/4.
]

这不是核结构的物理抑制，而是 AFH v6.0 接口中 isoscalar 系数的归一化。若散射截面前因子保留物理单核子耦合 (g_N)，则必须将 AFH 等标量响应映射为
[
oxed{
mathcal R_A^{m phys}(q)
=rac{16pi}{2J_A+1}W_{M,m AFH}^{00}(q).
}
]
factor four 只允许计入一次：或者放在核响应中，或者放在 amplitude-level isoscalar coupling contraction 中，不能两处重复。

内置密度矩阵是有限小数精度，因此本项目以每个同位素自己的计算零动量值消除极小的整体舍入偏差：
[
oxed{
mathcal R_A^{m phys}(q)
=A^2rac{R_{m AFH}(q)}{R_{m AFH}(0)}.
}
]
这只改变整体归一化，不改变 AFH 的 (q) 依赖或衍射极小值位置。

## 4. AFH 多极响应的数值闭合

本项目保存了每个同位素的 rank-0 与 rank-2 多极振幅 (a_0,a_2)。对本次审计所覆盖的弹性电荷响应，重构式为
[
mathcal R_{A,m rec}^{m phys}(q)
=C_Arac{4pi}{2J_A+1}
left(|a_0(q)|^2+|a_2(q)|^2ight),
]
其中 (C_A) 是与该同位素零动量归一化一致的常数。具体值由生成器归档的 `A0_normalization_factor` 给出。

重构与归档的 `R_equal_pn_normalized` 在 7×2401 个节点上逐点比较。此检查验证多极振幅、归一化和响应输出之间的代数闭合；它不是独立核结构模型之间的交叉验证。

## 5. 为什么 Xe 同位素有限动量响应不同

差异至少来自：

- 核质量不同：在固定 (E_R) 下，精确空间动量 (q_A) 依赖各同位素自己的核质量；
- 核子数和中子数不同：归一化为 (A^2) 后，有限尺寸形状仍不必相同；
- 单体密度矩阵和壳层占据不同：它们改变多极矩阵元与核电荷分布；
- 核自旋不同：允许的弹性多极展开不同。

七种 AFH 同位素中，Xe-128、129、130、132、134、136 的 (J_A=0) 或 (1/2)，本次弹性电荷响应只有 (L=0)；Xe-131 的 (J_A=3/2)，允许 (L=0,2)。Xe-131 的 rank-2 项仍然是电荷 (M) 响应，不是 SD 的 (Sigma') 或 (Sigma'')。

在 Xe-131 的单极振幅接近抵消时，rank-2 振幅可以填充单极衍射极小值。因此其总 (M) 响应的极小值可能比其他同位素浅。

## 9. 适用范围与限制

- AFH-7 覆盖天然氙原子丰度 0.998158；Xe-124 和 Xe-126 不在 AFH v6.0 默认密度矩阵归档中。
- 本审计不将 Helm 替代响应称为 AFH，也不将 Hybrid-9 称为完整 AFH-9。
- 本审计不重新计算 Eq. (6) 三体核反冲率，不处理探测器效率、能量分辨率、曝光或似然。
- AFH 多极重构闭合是对既有响应输出的内部检查；独立高精度 finite-sum 和 Mathematica 对照仍应分别按其原始审计文件理解。
- 原始 AFH 因子四只能计入一次。修改论文截面前因子时必须同步检查该约定，避免重复计数。
