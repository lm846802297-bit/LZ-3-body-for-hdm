# Paired S1 ensemble bootstrap archive

**Status:** `BOOTSTRAP_AND_RANDOMIZATION_DIAGNOSTIC_ONLY`

This directory stores the machine-readable outputs for the paired ten-seed Parametric/Full S1 ensemble-map uncertainty audit. The full method, interpretation, and limitations are documented in the [scientific report](../LZ_2026_PAIRED_S1_ENSEMBLE_BOOTSTRAP_AUDIT_2026-11-16.md).

## Provenance

- Immutable paired S1 production: [GitHub Actions run 43750948249](https://github.com/lm846802297-bit/LZ-3-body-for-hdm/actions/runs/43750948249), artifact `14176882910`.
- Production artifact SHA-256: `606397d9eac594008630a18b97f1e72fbbfa1d157e34779de7ce5fd0fe5b8cb5`.
- Ten independent seeds; 4,700,000 unique events; NEST commit `541b6430dae6ea289cf110c99f174a9187f7fdee`.
- Bootstrap: 100,000 paired seed-cluster replicates, RNG seed `2026111601`.
- Exact paired randomization: all 1,024 within-seed Parametric/Full label swaps.

## Interpretation

The bootstrap intervals are method-sensitivity diagnostics for a non-smooth, non-negative TV statistic with only ten independent clusters. They are not formal equivalence intervals. Failure to reject the paired randomization null is not evidence of Parametric/Full equivalence, and these outputs do not provide an official LZ detector-systematic covariance or likelihood.
