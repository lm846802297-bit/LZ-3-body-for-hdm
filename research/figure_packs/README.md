# Research figure packs

This directory contains reproducible figure collections associated with specific research analyses. Each child directory should include its own figure index, scientific scope notes, and a machine-readable manifest.

## Available packs

- [LZ 2026 AFH-7 / Hybrid-9 scientific figure pack](lz_2026_afh7_hybrid9/README.md): 13-figure atlas covering the Xe-131 fixed-speed benchmark, natural-xenon halo-folded spectra, AFH factor-four normalization, LZ one-dimensional efficiency fold, quadrature checks, and momentum/halo convention audits.

The AFH-7 and Hybrid-9 labels are kept distinct: AFH-7 uses the seven isotopes with official AFH v6.0 default density matrices; Hybrid-9 uses Helm only for Xe-124 and Xe-126. The pack does not claim a full nine-isotope AFH response or a detector-level LZ likelihood.
