## 计算层次与公式

笔记本按同一过程 `chi1 + A -> chi1 + A + s` 分三层计算：

1. 对 (W^2)、(z=\cos\theta_*) 和方位角平均积分，得到三体积分 (I_6)；
2. 乘以核响应和截面前因子，得到固定同位素、固定入射速度的 (d\sigma_A/dE_R)；
3. 对实验室速度分布积分，并按天然氙同位素数丰度求和，得到理论 (dR_{Xe}/dE_R)。

方位角权重包含 (1/(2\pi)) 平均；(z) 积分仍覆盖 ([-1,1])。代码将自然单位截面从 GeV(^{-3}) 转为 cm(^2)/keV，再转换为 events/(tonne year keV)。

## 核质量、丰度与 AFH 响应约定

核质量必须与仓库天然氙主计算保持一致：

[
m_A=(m_{\mathrm{atomic},A}-54m_e)u,
]

其中忽略电子结合能。七种 AFH 可用同位素的核质量已嵌入 notebook 第一节的 `nuclearMassesGeV`：

| Xe-129 | 120.04644920255713 |
| Xe-130 | 120.97675889895481 |
| Xe-131 | 121.90971983538435 |
| Xe-132 | 122.84034860362944 |
| Xe-134 | 124.70449146471256 |
| Xe-136 | 126.569174824876 |

来源为 `research/afh_default_density_natural_xenon_halo/input/natural_xenon_isotope_weights.csv`，SHA-256：
`fd1bb996e5f582c74c3c86d129f1d2dded510c65237d0a7b2ba08861f1d8c991`。

七种 AFH 可用同位素的天然数目丰度之和为 0.998158；Xe-124、Xe-126 因缺少 AFH default density matrix 而不计算，因此**不对七种丰度重新归一化**。靶材平均摩尔质量则使用全部九种天然同位素的丰度加权值：
`131.29276144779053 g/mol`。这两个约定不能混为一谈。

AFH `ResponseNuclear[y,1,0,0]` 返回 package 的 isoscalar (W_M^{00})。代码通过 (q=0) 归一化使物理等质子/中子响应满足 (R_A(0)=A^2)，因此 factor-four isoscalar-to-equal-p/n 转换包含在响应归一化中，不应再在截面前因子重复乘四。响应动量使用
[
q=\sqrt{2m_AE_R+E_R^2}.
]
