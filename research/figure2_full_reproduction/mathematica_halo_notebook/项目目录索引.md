# 三体暗物质散射项目文件索引

本目录汇集论文 Figure 2 复现、氙核结构、Mathematica 计算和独立核对材料。当前主笔记本为 `Figure2_halo_isotopes/Figure2_三体微分截面与天然氙事件率.nb`；该版本使用 FeynCalc 振幅与自旋迹、AFH 氙同位素核响应及 Mathematica `NIntegrate`。

## 目录导航

| 目录 | 内容 |
|---|---|
| `Figure2_halo_isotopes` | 当前完整 Figure 2 笔记本、AFH 文件、运行说明和验证资料 |
| `Figure2_cross_section` | 固定速度微分截面公式、计算和结果 |
| `Figure2_g2_1` | `g2=1` 的计算版本与结果 |
| `Figure2_Mathematica` | Mathematica 事件率计算早期整理版 |
| `Xe131_弹性截面_AFH` | AFH Xe-131 弹性散射核响应检查 |
| `Xe131_Mathematica_独立验证` | Xe-131 弹性截面的 Mathematica 独立验证 |
| `afh-source`、`v6` | AFH 程序、文档及原始版本副本 |
| `mathematica-results` | Mathematica、FeynCalc、FeynArts 等计算结果和开发记录，体积较大 |
| `full-dsigma-audit` | 截面审计 Git worktree，保留原位置以维持 worktree 关联 |
| `research` | GitHub 项目的本地工作副本 |
| `00_下载归档` | 从各项目目录导出的 ZIP 原样归档 |

## 建议阅读顺序

1. 阅读 `Figure2_halo_isotopes/使用说明.md`。
2. 运行 `Figure2_halo_isotopes/Figure2_三体微分截面与天然氙事件率.nb`。
3. 查看同目录中的 `完整运行与数值对照.md` 和 `独立验证/验证报告.md`。
4. 弹性 AFH 核响应检查见 `Xe131_Mathematica_独立验证`。

`Figure2_*` 目录包含不同阶段的版本；正式复现优先使用上面指出的当前主笔记本。`00_下载归档` 仅用于还原或传递压缩包，不作为另一份工作副本。`MG5_debug` 是 MadGraph 开发版本启动信息，不属于 Figure 2 计算输入。
