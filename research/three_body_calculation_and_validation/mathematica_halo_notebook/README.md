# 矢量耦合暗物质三体散射与天然氙反冲率

主笔记本：`矢量耦合暗物质三体散射与天然氙反冲率.nb`。将 `dmformfactor-V6.m` 与笔记本放在同一目录，安装 Mathematica 和 FeynCalc 后从头依次运行。笔记本按固定速度单核素微分截面、速度与同位素平均、总截面、事件率排列，使用极点宽度和 NIntegrate。

- `独立验证/`：AFH 核响应、弹性散射、相空间和数值收敛检查。各报告列出验证范围。
- `FeynRules_check/`：矢量耦合模型、生成顶角与 FeynArts/UFO 的脚本、FeynCalc 计算记录。脚本可能引用原计算机的软件路径或本地安装目录，需根据脚本调整；软件本体不包含在此整理中。
- `历史笔记本备份/`：本地保存的历史版本，不作为当前计算入口。
- `three_body_rate_engine.wl`：历史独立计算程序，供旧验证脚本使用；主笔记本的计算函数已写在笔记本内部。

固定速度 Xe-131 单点曾运行检查；完整事件率能谱和新增的全部嵌套积分尚未重新运行。设置耗时积分开关前请检查笔记本中的说明。第三方 FeynCalc、FeynArts、FeynRules 应按各自官方方式安装。
