# 独立 Mathematica 验证目录

本目录用于对三体散射的积分实现做独立核对。用户日常计算请以 [天然氙主笔记本](../../three_body_natural_xenon/矢量耦合暗物质三体散射与天然氙反冲率.nb) 为准；本目录的 Mathematica 笔记本属于验证实现，不是另一份主结果。

## 精确质量方案

本目录中的 `three_body_rate_engine.wl`、代表点脚本和验证笔记本均已切换到同一 AME2020/CODATA-2022 裸核质量函数。Xe-131 裸核质量为 `121.90992244721734 GeV`。验证笔记本里的旧缓存输出已经清空；运行输入单元后会生成当前结果。

## 重算命令

从仓库根目录执行：

```text
python research/three_body_calculation_and_validation/mathematica_halo_notebook/独立验证/point_target_independent.py
wolframscript -file research/three_body_calculation_and_validation/mathematica_halo_notebook/独立验证/multi_energy_convergence.wls
wolframscript -file research/three_body_calculation_and_validation/mathematica_halo_notebook/独立验证/halo_convergence.wls
python research/three_body_calculation_and_validation/phase_space_convergence.py --mode all
```
