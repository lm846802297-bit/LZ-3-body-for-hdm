# 三体截面独立验证与公开基准复现

## 本次结论和验证边界

本次检查在本机 Mathematica 14.2 与 AFH v6 程序上运行。已对 AFH 核响应归一化、AFH 弹性截面接口、三体截面前因子来源、代表点的耦合缩放与阈值进行了核对；并以独立 Dalitz 积分复现 PDG 的 muon 三体衰变树级宽度。muon 是不同的物理模型，支持所编写 Dalitz 相空间积分的归一化，并不独立证明本暗物质模型的 Dirac 自旋迹、核模型或完整截面。

## A. AFH Xe-131 的等标量响应和因子 4

源文件：`../dmformfactor-V6.m`，代码：`check_afh_normalization.wls`。加载 Xe-131 默认密度矩阵，取 `ResponseNuclear[0,1,0,0]`；对核自旋 J=3/2，定义 `R_raw=4 pi W_M^00(0)/(2 J+1)`。

| 量 | 数值 |
| --- | ---: |
| AFH 原始 W_M^00(0) | 1365.516293403943 |
| R_raw | 4289.895955714992 |
| 4 R_raw | 17159.583822859968 |
| A² = 131² | 17161 |
| 4 R_raw / A² | 0.9999174770036693 |
| 当前程序 R_A(0) | 17161 |
| 当前程序 R_A(200 keV) | 9.56767024757783 |

本程序用 `A² W(y)/W(0)`，明确强制零动量归一化为 A²；它相当于 `4 R_raw(y)` 再乘常数 C0=A²/(4 R_raw(0))，这里 C0≈1.00008253。此处 0.00825% 的差异是已应用的零动量归一化调整；本数值检查不能仅凭本身断言偏差的全部来源。物理耦合匹配和等标量约定必须一致，因子 4 不能在响应和耦合两边重复加入。AFH 原程序的 `SetCoeffsNonrel[1,c,0]` 在质子、中子基底写入各 c/2；如要分别等于同一输入 g，需使用 c=2g。O1 的弹性程序还采用它自己的 246.2 GeV 固定归一化标度，不能把该 setter 输入直接等同于本三体模型的耦合。

AFH 公共论文：https://arxiv.org/abs/1308.6288

## B. 复现 AFH 弹性微分截面公式

代码：`afh_elastic_B4.wls`。模型为 Xe-131，mchi=50 GeV、jchi=1/2、O1 质子输入 1、中子 0、ER=5 keV、v=300 km/s；取 AFH 的核质量约定 mT=131×0.938272 GeV。

- 原程序 `TransitionProbability[v,q]`：6.274144597105332e-7 GeV^-4。
- 原程序 `DiffCrossSection[ER,v]`：12.257002290034286 GeV^-3。
- 由概率手动计算 `mT/(2 pi v²) Ptot`：12.257002290034293 GeV^-3。
- 前两种截面的相对差：-5.55e-16。

这验证了 AFH 程序内部 B4 关系和调用、单位约定；概率和截面均来自同一 AFH 源，因此不构成独立核物理模型检验。该结果是二体弹性 EFT，不能作为三体截面直接值。

## C. 三体相空间和截面整体因子

参考 PDG Kinematics：https://pdg.lbl.gov/2024/reviews/rpp2024-rev-kinematics.pdf 。令 Q=p'+k、W²=Q²，则 `dPhi3 = dW²/(2 pi) dPhi2(Pin -> A' Q) dPhi2(Q -> chi1 s)`。按实验室固定靶、核反冲能量 ER 和暗粒子入射三动量大小 p，先对核反冲方位角积分：

`dPhi2(Pin -> A' Q)/dER = 1/(8 pi p)`。

令 `lambda_dim=(W²-(mchi+ms)²)(W²-(mchi-ms)²)`，Q 静止系的两体测度为 `dPhi2(Q -> chi1 s)=sqrt(lambda_dim)/W² × dz dphi/(32 pi²)`。若对 phi 使用归一化平均，则

`dPhi3/(dER dW² dz) = sqrt(lambda_dim)/W² /(256 pi³ p)`。

固定靶入射 flux 为 `4 mA p`。在矢量核流前导时间分量近似及论文约定下，平均后的矩阵元平方取 `4 mA² (g1 g2 gVN)² R_A L00/(mV²+2mA ER)²`。相乘得到

`dσ/dER = mA (g1 g2 gVN)² R_A /(256 pi³ p² (mV²+2mA ER)²) × Integral dW² sqrt(lambda_dim)/W² Integral dz <L00>phi`。

这解释程序为何使用 `sqrt(lambda_dim)/W²`：原稿定义的 lambda 是无量纲的 `lambda_dim/W⁴`。上述推导明确使用给定的核流前导近似、速度和角平均约定；核流完整相对论张量、gVN 的物理匹配及核响应的单体近似仍需要单独检验。

## D. 公开不同模型：PDG muon 三体衰变

公开基准：PDG Muon Decay Parameters https://pdg.lbl.gov/2014/mobile/reviews/pdf/rpp2014-rev-muon-decay-params.pdf 及 PDG Kinematics（上节链接）。脚本 `pdg_muon_dalitz.wls` 在树级 Fermi 理论与末态质量为零的近似下，采用独立不变量 s、t 的 Dalitz 区域，不调用 `Fig2`I6` 或其运动学映射：

`|M|² = 16 GF² s (m_mu²-s)`，`0<=s<=m_mu²`，`0<=t<=m_mu²-s`，`dΓ=|M|² ds dt/(256 pi³ m_mu³)`。

输入 `GF=1.1663787e-5 GeV^-2`，`m_mu=0.1056583755 GeV`。计算得到：

| 方法 | 宽度 GeV |
| --- | ---: |
| Mathematica NIntegrate Dalitz 积分 | 3.009178560994024e-19 |
| PDG 树级公式 GF² m_mu^5/(192 pi³) | 3.009178560994025e-19 |
| 相对差 | -1.11e-16 |

树级寿命 hbar/Gamma 约 2.18734762 微秒。MuLan 论文测得 2.1969803 微秒：https://arxiv.org/abs/1010.0991 。这不是声称该树级近似精确复现实验：电子质量、电磁辐射和其他修正尚未加入，GF 本身也来自 muon 寿命提取，故这里的寿命数值不是独立实验预测。

## E. 当前三体程序的参数和积分检查

`model_limits.wls`：固定 g2=1、极点宽度不变，把 couplingSq 从 1 调为 4，ER=200 keV、v=776 km/s、Xe-131、ms=300 keV、Delta m=1 MeV、积分阶数 {10,10,6}：截面由 1.9078008882067017 变为 7.631203552826807 GeV^-3，比例 4.000000000000000。速度改为 400 km/s 时该点相空间关闭、截面为 0。该项只验证当前计算的缩放与阈值行为；改变 g2 会改变极点宽度，不能将该缩放直接外推到变化 g2 的情形。

相同点的独立坐标与 NIntegrate 和原程序 Gauss {24,24,12} 对照为 869799.631622 与 869808.146587 GeV²，相对差 -9.7895e-6；两者仍共用 Dirac 迹与同一理论测度。

## J. AFH 等标量 setter 直接检查

脚本 `verify_afh_setter.wls` 调用真实 AFH 源码，并读取 O1 内部的质子和中子系数。输入 `SetCoeffsNonrel[1,1,0]` 得到相同的 p 和 n 系数；将等标量 setter 输入改为 2，两个内部系数均变为原来的 2 倍，符合接口把输入等分给 p、n 的代码定义。这里这些内部系数还包含 AFH 的 EFT 归一化；不能直接把它们当作当前三体 Lagrangian 的物理 gVN。与 Xe-131 原始 W00 归一化的检查一起说明因子 4 的实现方式，但仍不足以独立证明模型到核流的完整匹配。
