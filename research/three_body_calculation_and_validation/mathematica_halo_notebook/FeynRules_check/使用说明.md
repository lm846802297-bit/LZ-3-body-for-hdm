# FeynRules 模型与顶角检查

`ThreeBodyVV.fr` 将原稿相互作用写成 FeynRules 模型。chiOne、chiTwo 为 Dirac 费米子，scal 为实标量，med 为中性矢量；gX、gS、gN 均显式设为实数。gX 对应论文 g1，gS 对应 g2，gN 是点状 Dirac 核子耦合；核子不是 Xe-131 核模型，AFH 核响应另行处理。模型没有给出矢量扇区完整规范破缺、Goldstone 或 ghost，不能据此声称规范完备。

## 推导顶角

运行 `wolframscript -file derive_rules.wls`。FeynRules 2.3.49 的程序文件已随本研究目录放在 `feynrules-current/`；脚本从这里读取 `FeynRules.m`，再计算 `FeynmanRules[LInteraction]` 并检查厄米性。第一次运行仍需要 Mathematica。本机 Mathematica 14.2 的既有结果为：两个标量暗费米子顶角、两个矢量暗费米子顶角、一个点状核子矢量顶角，合计 5 个；相应结构分别为 `i gS`、`i gX gamma^mu`、`i gN gamma^mu`。`L-HC[L]` 计算出的剩余顶角数为零；保存的脚本记录输出 `CHECK: PASS`。符号表达式记录在 `feynrules_derived_rules.txt`。

这些顶角的暗费米子部分与本项目 FeynArts 手写模型的 gs、gv 结构和相对正号一致；并不自动检验传播子宽度、三体相空间、AFH 核响应或探测器率。

## UFO 导出

`ThreeBodyVV_UFO/` 保存本模型的 UFO 导出快照；`ufo_export_manifest.json` 与 `ThreeBodyVV_UFO/SHA256SUMS.txt` 记录来源和校验值。此快照通过 Python 3.14.7 导入检查，包含 8 个粒子/反粒子条目、5 个顶角和 3 个耦合。运行 `wolframscript -file export_ufo.wls` 可重新生成该模型。FeynRules 2.3.49 自带 UFO 模板中的两处 Python 2 `raise` 语句由脚本改成 Python 3 语法；物理顶角未修改。FeynRules 因本模型未定义电荷而提示将电荷设为零；本模型只包含指定的矢量媒介耦合，不包含电磁相互作用。重新导出使用本目录内的 FeynRules 2.3.49 程序文件。

此 UFO 尚未用于 MadGraph 计算散射截面。当前归档只验证 Python 模型文件可导入，不等于模型矩阵元或截面已验证。UFO 使用 chi2 的全局宽度；当前三体 notebook 的基准只在辐射后图分母加入固定宽度。未来进行数值对照前须统一宽度处方；进行零宽度对照时需确认相空间全程离壳。

官方项目：https://cp3.irmp.ucl.ac.be/projects/feynrules/wiki 。FeynRules 2 论文：https://arxiv.org/abs/1310.1921 。
