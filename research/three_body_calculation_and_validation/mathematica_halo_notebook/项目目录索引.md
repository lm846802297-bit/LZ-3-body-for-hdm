# 三体散射 Mathematica 目录索引

此目录保存与天然氙主笔记本互相验证所需的 Mathematica 引擎、独立相空间积分和 FeynRules/FeynArts 检查代码。正式主计算入口在 `../../three_body_natural_xenon/`。

| 文件或目录 | 用途 |
|---|---|
| `../../three_body_natural_xenon/矢量耦合暗物质三体散射与天然氙反冲率.nb` | 正式主笔记本；代码内联显示，AFH 输入与笔记本同目录 |
| `three_body_rate_engine.wl` | 独立迹函数和三体截面引擎，供对照脚本调用 |
| `independent_nintegrate.wl` | 独立运动学构造与 `NIntegrate` 相空间积分 |
| `FeynRules_check/` | ThreeBodyVV 模型、FeynRules 导出、FeynArts 图、FeynCalc 振幅及第三方程序源码 |
| `独立验证/` | AFH 核响应与数值方法的验证材料 |
| `convergence_halo.csv` | 已归档的速度积分收敛数据 |

从主 notebook 的验证区运行时，脚本、模型和软件包通过 `NotebookDirectory[]` 相对定位；不应依赖旧 `mathematica-results` 文件夹或其他电脑的绝对路径。主 notebook 中保留的历史输出可能显示旧机器路径，但那是保存的运行结果，不是可执行代码的路径来源。运行要求和验证边界见本目录 `README.md` 与 `FeynRules_check/使用说明.md`。
